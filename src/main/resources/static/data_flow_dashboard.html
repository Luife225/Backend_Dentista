¿Tu Base de Datos tiene la arquitectura de un SaaS? ¡SÍ, al 100%!

Tu base de datos implementa el patrón Multi-Tenant con Aislamiento Lógico por Tenant (SaaS Compartido). Cada clínica dental es un Tenant único (tabla clinica), y todas las entidades operativas (paciente, cita, atencion_clinica, version_odontograma, etc.) tienen la llave foránea clinica_id obligatoria con restricción única compuesta (uq_paciente_clinica). Esto garantiza que la Clínica "A" jamás pueda ver citas ni pacientes de la Clínica "B".

Modelo SaaS:Multi-Tenant DB Compartida
Segregación:Tenant Key (clinica_id)
Seguridad RBAC:Roles + Permisos JSONB
Integridad Histórica:Atenciones Versionadas

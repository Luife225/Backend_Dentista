### Resumen de Recursos por Tabla:
1. **`clinica`** -> `/api/v1/clinics`
2. **`usuario`** -> `/api/v1/auth`, `/api/v1/users`
3. **`rol`** -> `/api/v1/roles`
4. **`usuario_clinica`** -> `/api/v1/clinic-memberships`
5. **`paciente`** -> `/api/v1/patients`
6. **`cita`** -> `/api/v1/appointments`
7. **`atencion_clinica`** -> `/api/v1/clinical-encounters`
8. **`version_atencion_clinica`** -> `/api/v1/clinical-encounters/{id}/versions`
9. **`version_odontograma`** -> `/api/v1/odontograms`
10. **`hallazgo_odontograma`** -> `/api/v1/odontograms/{id}/findings`
11. **`archivo_adjunto`** -> `/api/v1/attachments`
12. **`notificacion`** -> `/api/v1/notifications`

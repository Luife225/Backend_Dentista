# Metadatos públicos necesarios para reproducir la preparación

Esta carpeta contiene dos JSON originales de anotaciones DENTEX y dos índices de sus ZIP, aproximadamente 2,06 MB. No incluye radiografías. Permite reconstruir la descarga selectiva desde otro equipo sin depender de la caché o las rutas de la primera PC.

Fuente: [DENTEX, distribución del autor](https://huggingface.co/datasets/ibrahimhamamci/DENTEX/tree/7b27ccc8e342dcb774f69adc6ca5e6c09fefce93/DENTEX). Revisión: `7b27ccc8e342dcb774f69adc6ca5e6c09fefce93`.

Las anotaciones se conservan byte por byte; los índices fueron extraídos de los directorios de los ZIP con las herramientas de auditoría. `.gitattributes` evita cambios de fin de línea en estos archivos, para mantener sus hashes.
